# ClinicOS presentation and demo

Start with the [four-page diagram guide](diagrams/clinicos-demo-diagrams.pdf), then use the [presenter script](presenter-notes/demo-script.md) for the live demonstration.

## Files by purpose

| Folder | Purpose |
| --- | --- |
| `diagrams/` | PDF for presenting or sharing the complete workflow guide. |
| `slide-images/` | Four 1920 x 1080 images, numbered in presentation order, ready to insert into slides. |
| `presenter-notes/` | A 10-minute demo script, preparation steps and an optional operations tour. |

## Presentation order

1. [Patient journey](slide-images/01-patient-journey.png) - arrival, care, payment and follow-up.
2. [Patient profile](slide-images/02-patient-profile.png) - where visits, history, reports and photographs live.
3. [Staff responsibilities](slide-images/03-staff-responsibilities.png) - each account's main work.
4. [Demo route](slide-images/04-demo-route.png) - the sequence for a short live presentation.

[Download the complete pack](clinicos-presentation-pack.zip) to share these materials together. The archive uses the same folder structure.

Use fictional DEMO records and files during presentations.
